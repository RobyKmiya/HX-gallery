# 画匣 1.1.0 · 使用说明

> 一个完全离线的本地画廊：把散落的图片压缩包收进来，有封面墙、评分、标签、合集和顺手的阅读器。
> **不联网、不注册、不上传任何文件。**

---

## 一、安装

1. 双击 `画匣_1.1.0_x64-setup.exe`，按提示装完（装到当前用户，不需要管理员权限）。
2. 桌面/开始菜单会出现「画匣」，双击启动。
3. 首次启动会让你**选一个库目录**——建议专门建一个，比如 `D:\画匣库`。

> 库目录就是画匣的全部数据：压缩包原件、索引、封面缓存都放在里面。
> 换电脑时把整个目录拷走，在新机器上重新「选择库目录」指向它即可。

---

## 二、三步上手

1. **选库目录** —— 见上。
2. **导入** —— 点「导入压缩包」选 ZIP / CBZ / 7Z / RAR，或直接把文件拖进窗口。
   一个压缩包 = 一个画集；包里的多张图 = 这个画集的很多页。
   源文件会**复制**进库（原文件不动），重复导入会自动去重。
3. **双击开始看** —— 阅读器里 `←` `→` 翻页，`F` 进沉浸模式，**右键**出菜单。

---

## 三、阅读器

### 快捷键

| 操作 | 按键 |
|---|---|
| 翻页 | `←` `→` `↑` `↓` / `空格` / `PgUp` `PgDn` |
| 首页 / 末页 | `Home` / `End` |
| 放大 / 缩小 / 适应页面 | `+` / `-` / `0`，或 `Ctrl+滚轮` |
| 双页 / 沉浸 / 缩略图栏 | `D` / `F` / `T` |
| GIF 播放（动图播完再翻页） | `Shift+P` |
| 幻灯播放（每 N 秒一页） | `Ctrl+1` ~ `Ctrl+9`，`Ctrl+0` 关闭，空格暂停 |
| 加书签 / 书签列表 | `B` / `L` |
| 上一本 / 下一本 | `Alt+←` / `Alt+→` |
| 收藏当前页（单页） | `P` |
| 收藏左页 / 右页（双页） | `[` / `]` |
| 复制当前页 | `Ctrl+C` |
| 在资源管理器中定位 | `Ctrl+Enter` |
| 老板键（藏窗 / 全局呼回） | `Ctrl+H` / `Ctrl+Shift+H` |
| 退出阅读 | `Esc` |

- **点击分区**：画面横向分三块——左区上一页、中区打开目录、右区下一页；两条分界线可拖动，位置会记住。
- **双击画面** = 进/出沉浸模式；鼠标缩放只认 `Ctrl+滚轮`。
- **右键菜单**：翻页、缩放、播放、书签、收藏页、复制当前页、设为桌面壁纸。
- **鼠标后退侧键**：沉浸模式下先退出沉浸，再按一次才退出阅读。
- 读到最后会**自动接下一本**；打开合集里的某一话，会按集数顺序连续往下读。

### 翻页方式

- **滚动**：连续滚动，适合长条本和快速扫。
- **分页**：一次一页（或双页），适合逐页细看。

两种方式在设置里切，右键菜单也能切。

## 四、整理

| 功能 | 在哪 | 说明 |
|---|---|---|
| 评分 | 详情面板 | 百分制，默认 60 分 |
| 标签 | 详情面板 → 标签 | 支持分类、翻译名、权重；标签中心可批量合并、一键保存全部修改 |
| 收藏夹 | 左侧栏 | 星形/爱心/圆形/正方形四种图标，8 种填充色可自定义 |
| 合集 | 选中多个画集右键 | 连载本按「集数顺序」排队，可改每话名字、设封面、封面墙看 |
| 待看目录 | 左侧栏 | 随机抽一批排队读，带进度 |
| 散图收藏夹 | 左侧栏 | 单图收藏，只记引用不复制文件 |
| 回收站 | 左侧栏 | 删除的画集先进回收站，可恢复 |

### 三处右键菜单

- **阅读器**：翻页 / 缩放 / 播放 / 图片操作。
- **画集卡片**：加入待看 / 移入回收站 / 打开所在位置 / 加入合集。
- **画廊空白处**：导入 / 刷新 / 切换视图 / 打开各面板 / 设置。

## 五、设置

侧栏「设置」里分五页：

- **通用**：网格滚动 / 分页浏览、详情面板浮动或停靠。

## 五·五、网页抓取能力（支持 5 站）

D2 面板（设置 → 更多入口 → 网页抓取）可以**整部抓取**作品页：粘贴详情页网址 → 点「开始抓取并入库」，画匣把整部图片逐张下载、打包成 CBZ 自动入库，并打上「D2下载」来源标签。

| 站点 | 详情页地址特征 | 说明 |
|---|---|---|
| exhentai / e-hentai | 含 `/g/数字/` | 需登录且账号有 exh 权限；白屏=未登录（`?poni=no`），系统代理 `127.0.0.1:65532` 要开着 |
| nhentai | `nhentai.net/g/数字/` | 走站内 API 取页表+标签，无需登录，取图片直链逐张下载 |
| 18comic（禁漫） | 含 `/album/数字/` | 多章节按章逐页抓全；新作品若图片混淆解析不出，可 Cookie 登录后重试 |
| wnacg（绅士漫画） | 含 `aid-数字` | 从图库页一次取全；支持 `wn01.cc` 等数字镜像域名 |

- **登录**：D2 面板「Cookie 登录」按站点域名粘贴浏览器 cookie（exhentai / 18comic / wnacg / nhentai 四预设）。
- **省事做法**：先在浏览窗口打开作品页确认能看图，再点「抓取当前页」，不用复制地址。
- **结果**：完成卡显示标题、张数、失败数、原文链接与首张图片，可「打开库目录」。
- **边界**：其余站点能正常浏览但暂无解析器；整站注入的油猴脚本（如 Comic Looms）可能与抓取脚本抢界面，冲突时以 D2 抓取按钮为准。

## 六、数据与安全

- 全部数据在本机库目录：压缩包原件 + `.gallery`（索引库、封面缓存、备份）。
- **不联网**，没有账号，不上传任何文件。
- 升级数据库前会自动备份到库目录 `.gallery\backups`。
- 想整体迁移：关闭画匣，把整个库目录拷到新位置，再启动时选择新路径。

## 七、常见问题

**Q：会偷偷联网吗？**
不会。画匣没有网络请求，断网也能用全部功能。

**Q：导入后源文件还在吗？**
在。导入是复制，源文件不动。

**Q：为什么有的画集显示「文件缺失」？**
压缩包被移动或删除了。可以在详情里「打开所在位置」找回，或移入回收站。

**Q：杀毒软件报警？**
这是自编译的独立程序，没有签名，个别杀软会提示。加信任即可。

**Q：删掉的画集能恢复吗？**
能，删到「回收站」，只要没清空就一直能还原。

**Q：阅读时窗口拖得很小还能用吗？**
侧栏可以一路拖到只剩图标；窗口最小 640×460。
